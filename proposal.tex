\section{Project Proposal}

\subsection{Introduction and Description of Work}
Magic: The Gathering (MTG) is a Collectible Card Game (CCG), created in 1993 by Richard Garfield \textemdash{} an American computational mathematician \textemdash{} for Wizards of the Coast (WotC).

Over 30 years later, the game remains immensely popular. To date, over 30,000 unique cards have been produced, in sets that now release around 6 times per year. WotC continues to produce the game under the ownership of Hasbro, who report that MTG is played by over 50 million people, and boast that it is their first ``\$1 Billion brand''.

A side-effect of MTG's immense popularity combined with its computational origins is a necessary exactness to the game rules, such that every rules question must have an objective resolution. This is achieved in two ways: firstly, an over-300 page long document of \href{https://magic.wizards.com/en/rules}{comprehensive rules}, which intentionally reads like a law book; and secondly, rules text on cards, which must adhere to the aforementioned comprehensive rules and unambiguously present the actions and abilities of the cards to the player, whilst remaining understandable enough to mentally parse.

Cards' rules text is collated in WotC's Gatherer database, wherein the most up-to-date version is known as ``Oracle Text''. A card's Oracle Text is its definitive reading, when it differs from the original printing. Oracle Text has been updated over time with the aim of clarifying ambiguity, incorporating rules changes, and \textemdash{} most importantly to this project \textemdash{} largely standardising the rules language.

The result of this is that Oracle Text lies somewhere between a natural language and an artificial language.

Academic papers have been written on MTG. Most notably, a 2019 paper proves that MTG is Turing Complete.

Previously, formal grammars have been produced (though not academically evaluated) which are successful in parsing a subset of Oracle text. These grammars tend to be hand-written rather than induced, likely owing to a lack of pre-annotated data available in this field.\bigskip

I propose the production of an Unsupervised Grammar Induction (UGI) system for MTG cards, which learns a grammar for Oracle Text. This system will enable Oracle Text to be automatically parsed into its inherent structure, which has the potential to lead to further applications such as automated code generation and semantic search (outside the proposed scope of this project).

As an initial extension, I will analyse how Oracle Text compares to natural English, through evaluation of an MTG trained grammar on natural English, and evaluation of an English trained grammar on Oracle Text.

This will involve the following subtasks:
\begin{itemize}
    \item Research existing UGI approaches
    \begin{itemize}
        \item Determine how appropriate each approach is to this use-case
        \item Determine the complexity of each approach
        \item Decide upon one approach to focus on for the implementation
        \item Research and understand the decided algorithm
        \item Research evaluation methods that do not rely on annotated data
    \end{itemize}
    \item Prepare test data
    \begin{itemize}
        \item Extract and store data from Scryfall/Gatherer API
        \item Filter out excluded cards
        \item Separate split cards
        \item Annotate a subset of data by hand for later evaluation
    \end{itemize}
    \item Implement data pre-processing
    \begin{itemize}
        \item Replace card name with \texttt{<CARDNAME>} token
        \item Strip reminder text
        \item Split text per ability/effect/line
        \item Perform lexing
    \end{itemize}
    \item Implement chosen UGI training algorithm in line with research
    \item Produce grammar through implemented algorithm
    \item Evaluate performance
    \begin{itemize}
        \item Evaluate against hand-annotated data
        \item Evaluate against unannotated data
        \item Evaluate performance of Oracle-trained grammar on natural English dataset (initial extension)
        \item Evaluate grammar trained on natural English against Oracle text (initial extension)
    \end{itemize}
\end{itemize}

There is plenty of room for further extensions, the description of which is outside the scope of this proposal.

\subsection{Success Criteria}

Project success depends on:
\begin{enumerate}
    \item A successful implementation of a UGI algorithm.
    \item A data gathering script which accesses an MTG API and stores a dataset locally. 
    \item A pre-processing system which accesses the MTG dataset and outputs UGI-ready data.
    \item A system for evaluation of the UGI output against hand-annotated data.
    \item A system for evaluation of the UGI output against unannotated data.
    \item A system for evaluation of the UGI output against pre-annotated natural English. (initial extension)
\end{enumerate}
